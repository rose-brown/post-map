# 월간선도50 TOP9 레이어 — 계획

2026-09-29. 원본 스펙 `docs/superpowers/specs/2026-09-27-lead50-layer-design.md` 의 확장.

## 목표

지역별 순위 1~9 만 별도 레이어 **"월간선도50 TOP9 (시세총액)"** 으로 복사해 켜고 끄며 본다.
핀 안에 순위 숫자를 넣는다 (강남구 1위 디에이치퍼스티어아이파크 → **1**).
원본 레이어 이름도 **"월간선도50 (시세총액)"** 으로 바꾼다 (사용자 요청 2026-09-29).
순위 기준은 `기준조건코드=A01` = 시세총액 (2026-09-29 실호출: A01 순위와 시세총액 역전 0건, A02 는 평당시세 순).

## 결정

| # | 결정 | 이유 |
|---|---|---|
| T1 | 레이어 **1개**. 69 지역의 1~9 위를 모두 담는다. | 스펙 D5 와 같은 이유 (레이어가 많으면 패널이 망가진다). |

## 단계

1. `markers.ts` 에 `n1`~`n9` → 지도·목록·선택 UI 에 보이는지.
2. `build.ts` 에 `LAYER_NAME` 변경 · `TOP9_LAYER_NAME` · 순수 함수 `top9Rows` → `tests/lead50.test.ts`.
3. `top9.ts` + `run.ts` 연결 → `--dry-run` 건수.
4. 서버: 원본 레이어 이름 변경, TOP9 생성.
5. 브라우저: 강남구 1위 핀에 1, 레이어 끄면 사라짐, 목록 → 정보 페이지.
   **위험**: 숨긴 레이어의 Terra Draw 점이 투명한 채 클릭될 수 있다. 좌표가 원본과 같아 원본 핀 클릭이 사본을 잡을 수 있다.
   재현되면 `MapView` 동기화 이펙트 수정 여부를 사용자에게 묻는다.

## 하지 않는 것

10위 이상 숫자, 순위별·지역별 레이어, Phase 2 필터·테이블.

## 추가 — 순위 구간 레이어 (2026-09-29, 사용자 결정)

원본 "월간선도50 (시세총액)" 을 **사본 없이** 나눴다. 기존 레이어는 id 를 유지한 채 TOP1~10 으로 이름을 바꿨다.

| 레이어 | 건수 (202608) | 처음 표시 |
|---|---|---|
| 월간선도50 TOP1~10 (시세총액) | 690 | 켬 |
| 월간선도50 TOP11~20 / 21~30 / 31~40 / 41~50 (시세총액) | 680 / 661 / 650 / 607 | 끔 |
| 월간선도50 순위 밖 (시세총액) | 0 | 끔 |
| 월간선도50 TOP9 (시세총액) — 사본 | 621 | 켬 |

- 매월 `run.ts` 가 순위로 구간 레이어를 고른다(`bandOf`). 같은 도형이 옮겨 가므로 메모·블록이 따라간다.
- 수집한 지역에서 순위에 없는 단지는 `retireRows` 가 순위 밖 레이어로 옮기고 ★ 를 뗀다 (D6 — 지우지 않는다).
- 표시 상태는 레이어를 **만들 때만** 정한다. 이후 켜고 끈 것은 덮지 않는다.
- 숫자 핀은 1~9 만 (사용자 결정). 10 위 이하는 ★ / 점 그대로. TOP9 은 TOP1~10 구간에서 사본을 만든다.
- 한계: TOP1~10 과 TOP9 을 같이 켜면 좌표가 같아 ★ 가 숫자를 덮는다.

## 같이 고친 것

- 앱이 서버에서 도형을 1000개만 읽던 버그 (`repo.ts` `loadAll` 페이지네이션).
- 레이어 표시 이펙트의 n² 갱신 (첫 화면 17초 → 4초, 원본 레이어 끈 상태 로컬 측정). 숨긴 레이어 도형은 Terra Draw 에서 뺀다.

## 추가 — 세대수로 포인트 크기 (2026-09-29, 사용자 결정)

- 레이어 스타일 `sizeField`(숫자 속성 키)로 점·핀 크기를 정한다 (`src/map/pointSize.ts`). 도메인 용어는 스크립트가 넣는 값(`households`)에만 있다.
- **로그 비례**: 같은 필드를 쓰는 모든 레이어의 최소~최대를 0~1 로. 점 반지름 3~14px, 핀 0.7~1.5배. 값이 없으면 기본 크기.
  면적 비례(제곱근)는 헬리오시티 9,510 하나 때문에 80% 가 4.8~7.6px 에 몰려 버렸다.
- 핀이 겹치면 레이어 순서가 뒤인(패널 아래쪽) 레이어가 위에 온다 (`symbol-sort-key`).
