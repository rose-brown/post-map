## 1. 공용 DB 질문

배포본(https://rose-brown.github.io/post-map/)에서 사용자 입력을 공용 DB 에 저장·공유하는 방법을 검토했다.

- 현재는 Phase 1 이라 데이터가 **각자 브라우저의 IndexedDB 에만** 있다. 같은 링크여도 서로 안 보인다.
- 방법은 PRD 의 Phase 3 계획 그대로 **Supabase**(Postgres + Auth + RLS + Realtime).
  `db/repo.ts` 의 공개 함수는 유지하고 내부만 Supabase 로 바꾸면 저장 게이트(불변 규칙 1)도 유지된다.
- 결정이 필요한 항목(보류): 쓰기 권한 범위(익명/로그인/초대), 실시간 반영 여부, IndexedDB 이관 여부.
- 주의: 검색·지오코딩은 dev 프록시라 배포본에서 동작하지 않는다. VWorld 약관 미확인 상태에서
  공용 DB 저장은 재배포 문제가 될 수 있다.
- **결론: PRD 순서대로 Phase 2 를 먼저 진행한다.**

## 4. 코드 조사에서 새로 확인한 사실

- **Terra Draw 는 MultiPolygon·구멍 있는 Polygon 을 거부한다** (`Feature has holes` / `Feature is not a Polygon`, dist 소스 확인).
  합집합·차집합 결과가 자주 이 형태다 → 별도 MapLibre 소스 `shapes` 로 그리고 선택만 허용, 꼭짓점 편집은 없음.
- 동기화 이펙트는 추가·고아 제거만 하고 **지오메트리 변경을 TD 에 되밀지 않는다** → 편집 Undo 를 위해 갱신 단계 추가 필요.
- 기존 Ctrl+Z 핸들러가 모드와 무관하게 TD 자체 `draw.undo()` 를 부른다 → 작도 중엔 TD, 선택 모드엔 스토어 Undo 로 분기.
- `repo.flush()` 가 피처 삭제 시 blobs 도 지운다 → 삭제 기록에 Blob 을 담아 두고 Undo 때 복원.
- `!f.derivedFrom` 이 "링이 아님" 의미로 쓰여 있다 (`FeatureList`, `LayerPanel`, `MapView`) → `isRing()` 으로 교체해야 연산 결과가 사라지지 않는다.
- 동심원 링 id 가 무작위라 중심 드래그 후 Undo 하면 고아 링이 남는다 → `rng_${centerId}_${radius}` 로 결정적 id.
- Turf 7.4 실측: 떨어진 합집합 → `MultiPolygon`, 안 겹친 교차·완전히 덮인 차집합 → `null`, 과도한 음수 버퍼·선의 음수 버퍼 → `undefined`.
- Node v24.18.0 은 `.ts` 를 직접 실행한다 → 계산 함수 TDD 를 의존성 없이 할 수 있다.
