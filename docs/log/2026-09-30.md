## 구현 중 찾은 것

- **콘솔에서 `import('/src/store/useStore.ts')` 는 빈 스토어를 준다.** `performance` 리소스 목록의 전체 URL
  (`http://localhost:5173/src/store/useStore.ts`)로 import 해야 앱과 같은 인스턴스다.
- **필터 입력이 한 글자에 1.0~1.7초 걸렸다** (dev). CPU 프로파일: Terra Draw 65ms, 나머지는 목록 행 렌더 —
  `metaOf` 의 `toLocaleString`(호출마다 포매터 생성)과 바뀌지 않은 `Row` 재렌더. 포매터 재사용 + `Row` memo +
  `useDeferredValue(filters)`(목록·지도)로 dev 4글자 연타 1,157→~800ms, **배포 빌드 402~529ms · 한 글자 150~290ms**.
- **Git Bash 에서 `BASE_PATH=/` 는 `/Program Files/Git/` 로 바뀐다** — 로컬 배포 빌드 확인은 `BASE_PATH=./`.
- `vite preview` 는 `base` 를 `'/'` 로 보므로(`command !== 'build'`) 기본 빌드(`/post-map/`)를 띄우면 흰 화면이다.
