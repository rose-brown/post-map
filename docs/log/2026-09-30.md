## 구현 중 찾은 것

- **콘솔에서 `import('/src/store/useStore.ts')` 는 빈 스토어를 준다.** `performance` 리소스 목록의 전체 URL
  (`http://localhost:5173/src/store/useStore.ts`)로 import 해야 앱과 같은 인스턴스다.
- **필터 입력이 한 글자에 1.0~1.7초 걸렸다** (dev). CPU 프로파일: Terra Draw 65ms, 나머지는 목록 행 렌더 —
  `metaOf` 의 `toLocaleString`(호출마다 포매터 생성)과 바뀌지 않은 `Row` 재렌더. 포매터 재사용 + `Row` memo +
  `useDeferredValue(filters)`(목록·지도)로 dev 4글자 연타 1,157→~800ms, **배포 빌드 402~529ms · 한 글자 150~290ms**.
- **Git Bash 에서 `BASE_PATH=/` 는 `/Program Files/Git/` 로 바뀐다** — 로컬 배포 빌드 확인은 `BASE_PATH=./`.
- `vite preview` 는 `base` 를 `'/'` 로 보므로(`command !== 'build'`) 기본 빌드(`/post-map/`)를 띄우면 흰 화면이다.

### 찾은 것

- **지도 점 클릭으로 선택이 되지 않는다** — 패널을 펼쳐도, 필터가 없어도, 배포본(main)에서도 같다. 이번 변경과 무관한 기존 문제이거나
  Playwright 클릭과 Terra Draw 의 궁합 문제일 수 있다. 손으로 눌러 확인해야 한다.
- HMR 뒤에는 스토어 모듈 URL 에 `?t=` 가 붙는다 — 콘솔 검산은 `performance` 리소스에서 URL 을 찾아 import 한다.
- 버튼 해제로 목록이 187 → 3,288 행으로 늘 때 dev 에서 개수 갱신이 0.2~0.8초 늦다 (useDeferredValue).

### 후속 (사용자 요청)

- 진입가 금액·총세대수를 누적(이하·이상) 버튼에서 **구간 버튼**으로 바꿨다: `~3억 · 3~5억 · 5~6.5억 · 6.5~8억 · 8~12억 · 12억~`,
  `~300 · 300~500 · 500~1000 · 1000~2000 · 2000~3000 · 3000~`. between 은 양끝 포함이라 상한을 한 칸 아래(4.99억, 1999세대)로 둔다.
- 경계를 구간 레이어와 맞추려고 `entryPrice` 를 반올림 → **내림**으로 (최종 검토 M-4 해소). 바뀐 단지 48. 버튼 개수 = 구간 레이어 개수
  (468/634/444/329/523/810), 세대 구간 합 3,288.
- "전체 월간선도50 레이어" 는 만들지 않기로 (사용자: 필터가 있으면 필요 없다). 순위 구간 레이어 6개를 켜면 전체다.
- "TOP9 에 필터가 안 된다" — dev 에서 재현되지 않았다(TOP9+진입가 3~5억+관광지, 3000~ → 56 = 51+5). 레이어 패널 숫자는 늘 전체라 헷갈릴 수 있다.

### 후속 2 (사용자 요청)

- **같은 항목 버튼 여러 개 동시 선택**: 버튼 조건에 `preset: true`, 같은 key 끼리 OR. 3~5억 + 5~6.5억 → 1,078 (=634+444), + 세대 1000~2000·2000~3000 → 353 (직접 계산과 같음).
- **점 클릭 → 정보 페이지가 안 열리던 버그**: 원인은 스토어 선택만 풀리고 Terra Draw 선택이 남는 것 (`selectFeature` 만 있고 해제가 없었다). TD 는 이미 선택된 도형을 다시 눌러도
  `select` 를 내지 않는다. 새로고침 직후 첫 클릭만 됐던 이유. 선택 동기화 이펙트에서 스토어 선택과 다른 TD 선택을 `deselectFeature` 로 푼다.
  PC: 점 → 닫기 → 같은 점 / 정보 열린 채 다른 점 / 목록 행 연속 / 행 → 닫기 → 점 모두 열림. 모바일: 같은 점 3번 반복 열림.
- **작은 창**: PC 레이아웃 최소 1100×600. 900×500 에서 문서가 1100×600 으로 스크롤돼 우측 패널까지 닿는다. 1280×800 은 스크롤 없음.
- **교통 레이어 맨 아래로**: 지하철 24 + 교통 필터 7 의 `order` 를 18~48 로 (37행 PATCH, 일회성). 나머지 순서 유지.
- **선릉 1시간 이내 레이어에 진입가 금액 버튼이 없던 것**: 교통 사본 7개는 9/29 transit 실행 때의 스키마·속성을 복사해 `entryPrice`·`ageYears` 가 없었다.
  `transit/run.ts` 재실행(dry-run 수치 9/29 와 같음, 삭제 0) → `presets/run.ts` (7레이어). 선릉 1시간 이내 1,885 중 entryPrice 1,841(나머지 거래 없음)·ageYears 1,885.
